### 🚀 Featured Projects

### 🌐 NetDevOps Closed-Loop Active Self-Healing Platform
**Enterprise Hybrid Network Auto-Remediation (In collaboration with ARTE, I.P.)**

*Active self-healing orchestration for hybrid corporate networks (Underlay MPLS + Overlay IPsec FortiGate VPN), reducing incident MTTR from 15-30 minutes to 4-7 seconds.*

#### 🛠️ Stack
`Python 3.11` • `n8n Orchestrator` • `NetBox SSoT` • `FortiOS REST API` • `Netmiko (PEP 668)` • `PRTG Webhooks` • `MongoDB` • `Docker` • `Metabase`

#### 🔥 What I Built & Key Highlights
- 🔄 **Event-Driven Closed-Loop Orchestration:** Autonomous detection via PRTG webhooks triggering state machines in n8n.
- 📖 **Single Source of Truth (SSoT):** Runtime network state validation and drift prevention against NetBox IPAM/DCIM.
- ⚡ **Synchronous Remediation:** Direct CMDB patch operations via FortiOS REST API with token auth and trusted host restrictions.
- 🛡️ **Out-of-Band Fallback Engine:** CLI contingency engine written in Python (Netmiko) running in isolated virtual environments under PEP 668.
- 🧪 **Chaos Engineering Audits:** 24 fault-injection scenarios tested (tunnel drops, BGP flaps, API timeouts) achieving 100% automated recovery.
- 📊 **Telemetry & Audit Trail:** Real-time MTTR calculations in Metabase with immutable incident logs stored in MongoDB.

👉 [**Explore the Repository & Architecture Diagram →**](https://github.com/RafaCr3z/netdevops-closed-loop-platform)

### 🛡️ CityGuards - Multi-Cloud Microservices & IaC Platform
**Fault-Tolerant Civic Reporting SaaS with Automated Cloud Infrastructure**

*Modular microservices platform with strict transactional control (ACID), multi-cloud persistence, and zero-trust CI/CD automation.*

#### 🛠️ Stack
`Azure App Service` • `Azure Functions` • `Azure Blob Storage` • `GCP Firestore` • `Azure Bicep (IaC)` • `GitHub Actions (OIDC)` • `Docker` • `Node.js`

#### 🔥 What I Built & Key Highlights
- ☁️ **Hybrid Multi-Cloud Architecture:** Azure compute layer seamlessly integrated with Google Cloud Firestore for synchronous NoSQL state.
- 🏗️ **Infrastructure as Code (IaC):** 100% of Azure cloud resources provisioned via modular `main.bicep` templates.
- 🔐 **Zero-Secret CI/CD Pipeline:** GitHub Actions deployments authenticated via Azure Federated OpenID Connect (OIDC) — no static secrets stored.
- 📦 **Containerized Deployments:** Container images built, scanned, and deployed using Azure Container Registry (ACR) and Container Instances.
- ⚙️ **Fault Tolerance & ACID Integrity:** Strict transaction controls preventing duplicate event processing and handling cloud failovers.
